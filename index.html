1.1 Bayes' theorem as an inference engine

Bayes' theorem tells us how to update a belief when we see new data.

Let H be a hypothesis (the thing we do not know) and D the data (what we observe).

P(H | D) = P(D | H) · P(H) / P(D)
posterior = likelihood × prior / evidence
  • Prior P(H): what we believe before seeing the data.
  • Likelihood P(D | H): how probable the data are if H is true.
  • Evidence P(D) = Σi P(D | Hi) P(Hi): a normalizing constant (law of total probability).
  • Posterior P(H | D): our updated belief. It becomes the prior for the next observation.

Odds form (very useful for sequential updating):

posterior odds = prior odds × likelihood ratio

It is an "inference engine" because it goes from effect to cause: we know P(data | cause), and we want P(cause | data).

1.2 Modes of convergence of random variables

Let X1, X2, … and X be random variables on the same probability space (Ω, F, P).

ModeNotationDefinitionIn words
In probabilityXn →P X for every ε > 0: P(|Xn − X| > ε) → 0 The chance of being far from X goes to 0.
Almost sureXn →a.s. X P( lim Xn = X ) = 1 ⟺ for every ε: P( supk≥n |Xk − X| > ε ) → 0 Almost every single trajectory converges.
Mean square (L²)Xn →L² X E[ (Xn − X)² ] → 0 The mean squared error goes to 0.
In distributionXn →d X Fn(x) → F(x) at every continuity point x of F Only the shape of the law converges, not the values.

How they relate

  • L² ⇒ in probability (Markov / Chebyshev): P(|Xn − X| > ε) ≤ E[(Xn − X)²] / ε².
  • a.s. ⇒ in probability, but not the reverse (typewriter sequence below).
  • L² and a.s. do not imply each other (typewriter: L² but not a.s.; spike: a.s. but not L²).
  • In probability ⇒ in distribution. Converse only if the limit is a constant.
  • Partial converses: in probability ⇒ a.s. along a subsequence; in probability + domination (|Xn| ≤ Y, E[Y²] < ∞) ⇒ L².

Laws of Large Numbers and CLT

Let X1, X2, … be i.i.d. with mean μ and variance σ² < ∞, and X̄n = (X1 + … + Xn)/n.

  • Weak LLN (in probability): X̄n →P μ. Proof: E[X̄n] = μ, Var(X̄n) = σ²/n, so by Chebyshev P(|X̄n − μ| > ε) ≤ σ² / (n ε²) → 0. The same computation shows E[(X̄n − μ)²] = σ²/n → 0, i.e. convergence in L².
  • Strong LLN (almost sure): X̄n →a.s. μ (Kolmogorov; only E|X| < ∞ is needed).
  • Central Limit Theorem (in distribution): Zn = √n (X̄n − μ) / σ →d N(0, 1).

The three results describe three different things: LLN says where X̄n goes (to μ); CLT says how fast and with which shape it fluctuates around μ (size σ/√n, Gaussian shape).

Part A — Convergence in probability theory

2.1 The four modes of convergence

Let (Ω, 𝓕, P) be a probability space and let X1, X2, … and X be random variables on it. A random variable is a function Xn(ω) of the outcome ω, so “Xn gets close to X” can be made precise in several non-equivalent ways. Each mode controls a different object: a probability, a whole trajectory, an average squared error, or just a distribution.

Convergence in probability P

Xn P→ X  ⇔  ∀ ε > 0:  P(|Xn − X| > ε) → 0

Meaning. For each fixed large n, the chance of a “big miss” is small. It controls every n separately: the set of outcomes where Xn misses may keep moving around, so a single trajectory can still miss infinitely often.

Role. Weak LLN; consistency of estimators; Slutsky’s theorem.

Almost sure convergence a.s.

Xn a.s.→ X  ⇔  P( limn→∞ Xn = X ) = 1

Meaning. For (almost) every single realisation ω, the ordinary numeric sequence Xn(ω) converges. Equivalent form: P(supk≥n|Xk − X| > ε) → 0, so it controls the whole tail of the sequence.

Tool. Borel–Cantelli: if Σn P(|Xn − X| > ε) < ∞ for all ε, then Xn → X a.s.

Role. Strong LLN (“one long run converges”); Glivenko–Cantelli; reliability of Monte Carlo and of the frequentist reading of probability.

Mean-square (L²) convergence L²

Xn L²→ X  ⇔  E[(Xn − X)²] → 0

Meaning. The average squared error vanishes. It is a “moment” mode: it punishes rare but huge errors. For an estimator it is exactly MSE(θ̂n) = Var(θ̂n) + Bias² → 0.

Tool. Chebyshev/Markov inequality; L² is a Hilbert space, so conditional expectation is an orthogonal projection (best mean-square predictor).

Role. Easiest proof of the LLN when σ² < ∞, since Var(Xn) = σ²/n → 0; time-series “ergodic in mean square”; MSE-consistency.

Convergence in distribution d

Xn d→ X  ⇔  Fn(x) → F(x) at every continuity point of F

Equivalent forms. E[f(Xn)] → E[f(X)] for all bounded continuous f; or characteristic functions φn(t) → φ(t) for all t (Lévy’s continuity theorem).

Meaning. Only the laws converge. The Xn need not even live on the same probability space, and nothing is said about Xn(ω) being close to anything.

Role. Central limit theorem, asymptotic confidence intervals and tests, delta method.

2.2 How the modes relate

  • L² ⇒ P by Chebyshev: P(|Xn − X| > ε) ≤ E[(Xn − X)²] / ε².
  • a.s. ⇒ P ⇒ d. Pointwise convergence of numbers pushes probabilities of big misses to 0; closeness of values pushes laws together.
  • d ⇒ P only for constant limits: if Xn → c in distribution, then Xn → c in probability.
  • Partial converses. (i) If Xn → X in probability, some subsequence converges a.s. (ii) a.s. convergence plus a dominating integrable bound (dominated convergence) or uniform integrability gives convergence of moments, hence Lp. (iii) Skorokhod: if Xn → X in distribution, there exist copies on a common space that converge a.s.

Counter-examples that explain the gaps

P (and L²) but not a.s. — the independent “rare flashes”

Let Xn be independent Bernoulli(1/n). Then P(Xn = 1) = 1/n → 0, so Xn → 0 in probability, and E[Xn²] = 1/n → 0, so also in L². But Σ 1/n = ∞ and the events are independent, so by the second Borel–Cantelli lemma Xn = 1 infinitely often with probability 1: no trajectory converges to 0.

Moral: convergence in probability says the flashes get rarer, not that they stop.

a.s. but not L² (nor L¹) — the escaping spike

Let U ~ Uniform(0,1) and Xn = n·1{U < 1/n}. For every U > 0, once n > 1/U we have Xn = 0, so Xn → 0 a.s. But E[Xn] = 1 and E[Xn²] = n → ∞.

Moral: a.s. convergence ignores how large the rare misses are; L² does not.

d but not P — same law, different variable

Let X ~ N(0,1) and Xn = −X for all n. Every Xn has the N(0,1) law, so Xn → X in distribution, but |Xn − X| = 2|X| does not shrink, so there is no convergence in probability.

2.3 Their roles in the LLN and the CLT

Throughout, X1, X2, … are i.i.d. with mean μ and variance σ², Sn = X1 + … + Xn, Xn = Sn/n.

Law of Large Numbers

Weak LLN (Khinchin). If E|X| < ∞:  Xn P→ μ.

Strong LLN (Kolmogorov). E|X| < ∞ ⇔  Xn a.s.→ μ.

L² version. If σ² < ∞: E[(Xn − μ)²] = σ²/n → 0, i.e. Xn L²→ μ.

One-line proof of the weak LLN (finite variance). By Chebyshev, P(|Xn − μ| > ε) ≤ Var(Xn)ε² = σ²n ε² → 0. The same computation is exactly the L² statement, which is why L² ⇒ P is the natural route.

Why two versions? The strong LLN says the single realised sequence of averages converges, which is what justifies “repeat the experiment many times and the relative frequency settles”. The weak LLN needs less and is enough for consistency of an estimator.

Central Limit Theorem

Lindeberg–Lévy. If 0 < σ² < ∞: Zn = √n (Xn − μ)σ = Sn − nμσ √n d→ N(0, 1).

Sketch (characteristic functions). Let Y = (X − μ)/σ, with φY(s) = 1 − s²/2 + o(s²). Then φZn(t) = [ φY(t/√n) ]n = [ 1 − t²2n + o(1/n) ]n → e−t²/2, the characteristic function of N(0,1); Lévy’s continuity theorem gives convergence in distribution. Notice that the t/√n inside φY is exactly what makes the second-order term of size 1/n.

Rate. Berry–Esseen: supx|P(Zn ≤ x) − Φ(x)| ≤ C E|X − μ|³ / (σ³ √n), with C < 0.48.

LLN and CLT are two zoom levels of the same fact

The LLN says Xn − μ → 0 (a.s., in P, in L²). The CLT zooms in by the factor √n and shows what is left: Xn ≈ μ + (σ/√n)·Z with Z ~ N(0,1). The first is about values (strong modes); the second can only be about distributions.

Why the CLT cannot be upgraded. Zn does not converge in probability, let alone a.s., to any random variable: Zn and Z2n have correlation 1/√2 for every n, so they never become close to each other. The sequence keeps fluctuating forever; only its shape stabilises.

    2.4 Why does √n keep appearing?

    (a) Additivity of variance

    For any random variables,

    Var(Sn) = Σi Var(Xi) + 2 Σi<j Cov(Xi, Xj)

    If the Xi are independent (or merely uncorrelated), all covariances vanish and the variances simply add: Var(Sn) = nσ². The standard deviation is the square root of the variance, so it grows like σ√n, not like n. Positive and negative deviations partly cancel; independent errors add up “in quadrature”, like the sides of a right triangle. Consequently

    sd(Xn) = σ√n,    Var(Xn) = σ²n

    (b) √n is the one scaling that keeps the fluctuation alive

    We have Sn − nμ of typical size σ√n. Dividing it by a normaliser bn gives three regimes:

    Normaliser bnLimit of (Sn − nμ)/bnResult
    bn = n0 (degenerate)LLN: the fluctuation is crushed
    bn = nα, ½ < α < 10still too much division
    bn = √nN(0, σ²)CLT: the only non-degenerate scale
    bn = nα, α < ½±∞ (variance blows up)too little division

    So the LLN is the statement at scale n (limit 0) and the CLT is the statement at scale √n (limit N(0, σ²)). Equivalently, the error of the sample mean is of order n−1/2: Xn − μ = OP(n−1/2).

    (c) The role of independence

    • Uncorrelated is enough for the variance formula, but not for the CLT. The CLT needs independence or a weaker substitute (Lindeberg–Feller for independent non-identical variables, martingale differences, mixing conditions).
    • Weak dependence keeps √n but changes the constant. For a stationary sequence with Σ|γ(k)| < ∞, Var(Sn)/n → σ2LR = γ(0) + 2Σk≥1γ(k). For an AR(1) with correlation ρ this is a factor (1+ρ)/(1−ρ) larger than the i.i.d. value: using σ/√n then underestimates the true error.
    • Strong dependence changes the rate. With long memory (γ(k) ~ k−a, 0 < a < 1) the sd of Sn grows like n1−a/2. In the extreme X1 = X2 = … there is no averaging at all: Var(Xn) = σ² for every n.
    • Heavy tails change the rate too. If Var(X) = ∞ the normaliser becomes n1/α (stable laws, α < 2). For the Cauchy distribution the mean of n observations has the same Cauchy law as one observation: no LLN, no CLT (try it in demo 1).

    (d) What this means in statistical inference

    • Standard error of a mean: σ/√n. Precision grows only like the square root of the data: to halve the error you need four times as many observations.
    • Confidence interval x ± z1−α/2 · s/√n and z-statistic z = √n(x − μ0)/s come directly from the CLT; the √n makes the statistic of order 1 under the null.
    • Monte-Carlo error decays as 1/√n regardless of dimension.
    • Estimators: “√n-consistent and asymptotically normal”, √n(θ̂ − θ) → N(0, I(θ)−1), is the benchmark for parametric models. Nonparametric estimators are slower (e.g. kernel density estimation: n−2/5), so √n is the parametric standard, not a universal law.
    • Bayesian link: the posterior standard deviation also shrinks like 1/√n (Bernstein–von Mises, see Part B).

    Part B — Conditional probability and Bayesian inference

    2.5 Conditional probability

    P(A | B) = P(A ∩ B)P(B),    P(B) > 0

    It is the probability of A in the “restricted universe” where B is known to have occurred; P(· | B) is itself a legitimate probability measure. Immediate consequences:

    • Multiplication (chain) rule: P(A ∩ B) = P(A | B) P(B), and P(A1 ∩ … ∩ Ak) = Π P(Aj | A1…Aj−1).
    • Law of total probability: for a partition B1,…,Bk,  P(A) = Σj P(A | Bj) P(Bj).
    • Independence means conditioning changes nothing: P(A | B) = P(A).
    • Densities: f(x | y) = f(x, y) / fY(y); and the conditional expectation E[Y | X] is the best predictor of Y from X in the L² sense (it minimises E[(Y − g(X))²]) — a nice link with Section 2.1.

    Where it lives in statistics

    • The statistical model is a conditional distribution: p(x | θ) is the law of the data given the parameter. Frequentists treat θ as a fixed unknown; Bayesians as a random variable, so p(x | θ) is a genuine conditional probability.
    • Regression models E[Y | X = x]; classification models P(class | features); Markov chains and hidden Markov models are built from P(Xt+1 | Xt); sufficiency means the conditional law of the data given the statistic does not depend on θ.
    • Hypothesis testing works with P(data as extreme | H0). It is not P(H0 | data): confusing P(A | B) with P(B | A) is the “prosecutor’s fallacy”, and Bayes’ theorem is exactly the bridge between the two.

    2.6 Bayes’ theorem and the three components

    From P(A ∩ B) = P(A | B)P(B) = P(B | A)P(A) we get

    P(A | B) = P(B | A) P(A)P(B) = P(B | A) P(A)Σj P(B | Aj) P(Aj)

    In statistical inference, A becomes the parameter θ and B becomes the observed data x:

    π(θ | x) = L(θ; x) · π(θ)∫ L(θ′; x) π(θ′) dθ′  ∝  L(θ; x) × π(θ)

    Prior π(θ)

    What we believe about θ before seeing the data: expert knowledge, earlier studies, a base rate, or deliberately vague (“weakly informative”). It is a probability distribution on the parameter space.

    Likelihood L(θ; x)

    The model’s probability p(x | θ) of the observed data, read as a function of θ. It says how well each θ explains the data. It is not a probability distribution over θ: it need not integrate to 1.

    Posterior π(θ | x)

    What we believe about θ after seeing the data. A proper distribution: it supports direct statements such as P(θ ∈ I | x) = 0.95, point estimates (mean, mode = MAP) and predictions.

    How the update works

    1. Multiply prior and likelihood point by point: parameter values that were plausible and explain the data well get a large product.
    2. Normalise by the evidence p(x) = ∫ L π (the denominator), so the result integrates to 1. The denominator does not depend on θ, hence “posterior ∝ likelihood × prior”.
    3. Odds form: posterior odds = prior odds × likelihood ratio (Bayes factor): P(H1 | x)P(H0 | x) = P(H1)P(H0) × p(x | H1)p(x | H0).
    4. Sequential updating: today’s posterior is tomorrow’s prior. For conditionally independent observations, updating in one batch or one observation at a time gives the same answer, regardless of order.

    Why this updating plays a central role in (Bayesian) inference

    • It answers the question people actually ask: “how probable is the hypothesis/parameter given what I observed?” — P(θ | x), not P(x | θ).
    • Coherent learning: evidence accumulates by a single rule; no ad-hoc combination of old and new information.
    • Prior information is used, which matters most with small samples, rare events and hierarchical or sequential problems.
    • Uncertainty is carried through to decisions: predictive distributions p(xnew | x) = ∫ p(xnew | θ) π(θ | x) dθ and expected-loss decision rules.
    • Connections to frequentist tools: with a flat prior the posterior mode equals the MLE; a Gaussian prior gives ridge (L²) regularisation, a Laplace prior gives lasso (L¹); for large n the posterior is approximately N(θ̂, I(θ̂)−1/n) (Bernstein–von Mises), which is the CLT again.

    Lesson.     Beta(α, β) × Binomial(k of n) ⟹ Beta(α + k, β + n − k)
    posterior mean = α + kα + β + n = w · kn + (1 − w) · αα + β,   w = nα + β + n

    The posterior mean is a weighted average of the data (MLE k/n) and the prior mean; α + β acts as the “prior sample size”. As n grows, w → 1: the data overwhelm the prior.

Evidence accumulates multiplicatively on the odds scale; a handful of moderately informative words can turn a 40% prior into 99.5% (with “free” and “winner”: odds 0.67 × 15 × 20 = 200 → 200/201). The same machinery is used in real spam filters, but the conditional-independence assumption is rarely true (“free” and “winner” are strongly correlated), so the output probability is over-confident even if the ranking is good.

    2.8 Advantages, limitations, and influence on conclusions

    Advantages

    • Direct probability statements about parameters and hypotheses (credible intervals, P(H | data)).
    • Natural incorporation of prior knowledge — decisive for rare events (base rates) and small samples.
    • Sequential, coherent updating; easy to combine data sources and to build hierarchical models.
    • Full predictive distributions and a clean link to decision theory.
    • Regularisation arises naturally (priors = penalties); works when the MLE is unstable.

    Limitations

    • Prior subjectivity: different priors can give different posteriors with little data; “non-informative” priors are not unique, and improper priors can give improper posteriors.
    • Cromwell’s rule: a prior probability of exactly 0 (or 1) can never be changed by any data.
    • Model dependence: a wrong likelihood (e.g. naive independence) gives confident but wrong posteriors.
    • Computation: the evidence integral is rarely closed-form; conjugate cases are the exception, otherwise MCMC or variational methods are needed.
    • Likelihood-based inference ignores the sampling plan; the likelihood is not a distribution over θ and must not be read as one.

    How priors and likelihoods shape the conclusion

    • Likelihood strength vs. prior strength. A sharply peaked likelihood (lots of data or very precise measurements) dominates a diffuse prior; a tight prior dominates a flat likelihood. Example A is a case where a very concentrated prior (π = 0.1%) beats a strong likelihood.
    • Small data → prior matters. In Example B the posterior mean is a weighted average with weight n/(α + β + n) on the data.
    • Large data → prior washes out (as long as it gives positive mass near the truth), and the posterior concentrates with width ∝ 1/√n: the Bayesian counterpart of the LLN (posterior consistency) and of the CLT (posterior ≈ normal).
    • Best practice: report the prior, run a sensitivity analysis with several reasonable priors, check the model, and compare with a frequentist analysis when possible.
    • Interpretation differs: a 95% credible interval is a probability statement about θ given the observed data; a 95% confidence interval is a statement about the procedure over repeated samples.

    2.9 Self-check questions

    Try to answer before opening each one.

    1. Does almost sure convergence imply convergence in probability? And the converse?

    Yes, a.s. ⇒ P. The converse is false (independent Bernoulli(1/n) variables converge to 0 in probability but not a.s.); it holds only along a subsequence.

    2. Why can’t the CLT be stated as convergence in probability of Zn?

    Because Zn keeps fluctuating: the correlation between Zn and Z2n is 1/√2 for every n, so they never get close to each other. Only the distribution stabilises.

    3. Why is the standard error of the mean σ/√n, and what changes if the data are positively correlated?

    Independence ⇒ variances add ⇒ Var(Sn) = nσ² ⇒ Var(Xn) = σ²/n. With positive correlation the covariance terms are positive, Var(Xn) is larger (for AR(1): ×(1+ρ)/(1−ρ)), and σ/√n understates the real error.

    4. A test has 99% sensitivity and a 2% false-positive rate. Why can P(attack | alert) still be small?

    Because the posterior also depends on the prior: if attacks are rare (π small), false alarms from the huge number of normal events outnumber true detections. Posterior = sens·π / (sens·π + fpr·(1−π)).

    5. Is the likelihood a probability distribution over θ?

    No. It is p(x | θ) viewed as a function of θ for the fixed observed data; it does not have to integrate to 1 over θ. Only after multiplying by a prior and normalising do we get a distribution over θ.

    6. What happens to the posterior as n → ∞, and why does the prior stop mattering?

    The likelihood becomes sharply peaked around the true value (width ∝ 1/√n), so the posterior concentrates there and becomes approximately normal, whatever the prior, provided the prior gives positive mass near the truth.

    In one paragraph

    The four modes of convergence differ in what they control: a probability (P), a whole trajectory (a.s.), a mean squared error (L²) or just the law (d). The LLN lives in the strong modes (the average converges to μ), the CLT lives in the weakest one (the fluctuation, rescaled by √n, has a normal shape); √n arises because independent variances add, so the sd of a sum grows like √n. Bayes’ theorem turns the conditional probabilities of the model (likelihood) and the initial belief (prior) into a belief about the parameter after the data (posterior); with little data the prior matters, with a lot of data the likelihood — and again 1/√n — takes over.
